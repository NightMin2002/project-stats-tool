🎯 智能过滤说明
──────────────────────────────────────────────────────

【自动排除的第三方库】
1. 库目录:
   lib, libs, library, vendor, vendors
   third-party, external, plugins
   bower_components, jspm_packages

2. 压缩文件:
   .min.js, .min.css
   -min.js, -min.css
   .bundle.js, .bundle.css

3. 知名库文件名:
   jquery, bootstrap, lodash, react, vue, angular
   moment, axios, d3, chart, echarts, three
   katex, markdown-it, highlight, prism
   dompurify, texmath, mathjax

【实际效果】
- Notes 项目: 排除了 6 个第三方库文件
- 总字符从 817KB 降至 359KB
- Tokens 从 ~300K 降至 ~133K
- 真实反映项目代码量 🎯


🚀 使用方法
──────────────────────────────────────────────────────

【方法 1】完整统计（推荐）
  双击: 统计项目.bat
  功能: 统计 + 报告 + 文字提取 一步完成

【方法 2】仅文字提取
  双击: 提取文字.bat
  功能: 只提取文字，不进行统计

【方法 3】拖放操作
  将项目文件夹拖到任一 .bat 文件上

【方法 4】命令行
  node project-stats.js [路径]  # 完整统计
  node extract-text.js [路径]   # 仅提取文字

【方法 5】项目内使用（最佳实践）
  1. 在项目根目录创建"统计工具"文件夹
  2. 将所有工具文件复制进去
  3. 进入文件夹，运行相应批处理
  4. 结果自动保存在 results 文件夹


📊 统计内容
──────────────────────────────────────────────────────

1. 项目信息
   - 项目名称和路径
   - 自动检测的项目类型

2. 文件统计
   - 统计文件数（实际代码）
   - 排除文件数（第三方库）🆕
   - 按语言分布

3. 文字统计
   - 中文字符数
   - 英文单词数
   - 总字符数和文件大小

4. 代码统计
   - 总行数
   - 代码行、注释行、空白行的数量和占比

5. 复杂度分析
   - 平均行长度
   - 平均文件大小
   - 最大文件和最长行

6. Tokens 估算
   - 基于实际代码的准确估算
   - 不包含第三方库

🎯 注意事项
──────────────────────────────────────────────────────
• 需要安装 Node.js 环境
• Tokens 估算为粗略值，实际可能有 ±20% 偏差
• 大型项目统计可能需要几秒钟
• 完整提取文件可能很大（几MB到几十MB）
• 二进制文件和无权限目录会自动跳过
• 工具会自动识别并排除自身所在目录
• results 文件夹不会被统计
• 第三方库文件会被智能识别并排除 🆕
• 即使在项目内使用，也不会影响统计结果


🛡️ 安全说明
──────────────────────────────────────────────────────
✅ 工具只读取文件，不修改任何项目文件
✅ 自动排除敏感目录（.git, node_modules 等）
✅ 支持 .gitignore 规则，尊重项目配置
✅ 所有结果仅保存在 results 文件夹
✅ 提取的文字内容是纯文本，无安全风险
✅ 智能识别第三方库，保护项目隐私 🆕
