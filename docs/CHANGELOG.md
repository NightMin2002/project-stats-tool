# 📋 更新日志

## [v2.12.1] - 2025-12-06 - 工作流优化版

### 🚀 工作流改进
- **极速启动** - 重构 `统计项目.bat`，直接调用 Node.js 核心逻辑，跳过网络检查，实现秒级启动。
- **维护分离** - 将自动更新逻辑剥离为独立的 `检查更新.bat`，用户可按需手动更新工具，不再影响日常使用体验。
- **历史查看器升级** - `view-history.js` 现在支持自动扫描 `results/` 目录下的所有项目，并提供交互式菜单供用户选择查看。

## [v2.12.0] - 2025-12-06 - 性能增强与多项目支持版

### 🚀 核心性能与架构优化
- **极速扫描引擎** - 在 `project-scanner.js` 中启用 `readdir({ withFileTypes: true })`，大幅减少 `fs.stat` 调用，文件扫描速度显著提升。
- **并行报告生成** - `OutputManager` 全面升级为并行写入模式，瞬间生成所有报告文件。
- **并发控制** - 优化文件操作，避免在超大项目中触发 `EMFILE` 错误。

### 🔄 多项目支持与隔离
- **按项目隔离历史** - 历史记录现在按项目名称自动分类存储 (`results/<ProjectName>/history.json`)，不再混用全局历史。
- **精准对比分析** - 修复了多项目统计时历史对比混乱的问题，确保只对比同一个项目的历史数据。
- **拖拽分析支持** - 修复了将文件夹拖拽到 `统计项目.bat` 时的路径错误问题，现在完美支持拖拽启动。

### 🛡️ 智能健壮性
- **智能自身排除** - 工具现在能自动识别自己的运行目录，防止将工具自身的代码计入统计结果（无需手动添加 .gitignore）。
- **历史记录备份** - 新增自动备份与恢复机制，防止因意外中断导致历史记录损坏。

### 📚 文档更新
- 更新了所有文档以反映最新的目录结构和功能特性。

## [v2.11.0] - 2025-11-07 - 可视化历史对比增强

### 🔄 新增功能
- HTML 报告增加“历史对比分析”区块（自动对比上一轮统计：文件数 / 总字符 / 总行 / 代码行 / 注释行 / Tokens）
- 以卡片形式展示增量与百分比变化，并通过趋势图标（📈 / 📉 / ➡️）指示状态
- 一键“隐藏对比 / 显示对比”按钮，支持折叠该区块，提升浏览长报告时的可控性

### 📈 趋势协同
- 历史趋势图与对比卡片并行展示（需要 ≥ 2 条历史记录）
- 数据统一来源自 `results/history.json`，保证一致性与可追溯性

### 🧩 模块化改动
- 新组件：`generateComparisonSection()`（`templates/components.js`）
- 新样式：对比卡片与开关按钮（`templates/styles.css.js`）
- 新逻辑：折叠/展开绑定（`templates/scripts.js`）
- 模板签名重构：`html-report-template.js` 改为接收 `options`（包含 `trendData` 与 `comparisonData`）
- 生成器扩展：`html-generator.js` 在非首次统计时传入对比数据

### 📚 文档更新
- `docs/AI-项目结构说明.md` 补充 comparisonData 与 options 结构说明
- `docs/使用说明.txt` 增加对比区块使用示例与交互说明

### ✅ 使用提示
运行第 2 次及以后即可在 HTML 中看到“历史对比分析”区块；需折叠时点击右上角按钮即可。

## [v2.10.0] - 2025-11-02 - 模块化重构版

  - `text-generator.js` - Markdown/TXT 报告生成
  - `tree-generator.js` - 目录树生成
  - `output-manager.js` - 统一文件保存管理
- `utils/` - 通用工具
  - `file-utils.js` - 文件工具
  - `formatters.js` - 格式化工具
