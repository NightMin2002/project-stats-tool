## [v3.2.0] - 2025-12-16 - Ω 极致美学版

### 🎨 视觉体验全面升级
- **文件大小热力图** - 全新的可视化组件，以热力图形式展示项目中最大的50个文件，颜色从冷色到暖色表示文件大小，一眼识别"膨胀"文件。
- **增强选择高亮** - 自定义 `::selection` 样式，选中文本时呈现品牌色光晕效果。
- **极致滚动条** - 渐变色滚动条替代系统默认样式，滚动体验更沉浸。
- **交互动画升级** - 卡片悬停缩放、进度条发光、图标脉动、趋势箭头弹跳等微交互动画。
- **响应式优化** - 完善移动端布局，支持平板和手机浏览报告。
- **打印样式支持** - 新增 `@media print` 样式，报告可直接打印或导出PDF。

### 🖥️ CLI 体验升级
- **美观进度条** - 全新的终端进度条，支持百分比、ETA预估、动态文件名显示。
- **预扫描提示** - 扫描前先统计文件数量，让用户对扫描规模心中有数。
- **彩色输出** - 使用 ANSI 色彩代码美化终端输出（支持 TTY 检测）。
- **加载动画** - Spinner 动画用于无进度值的等待场景。

### 🔧 扩展性增强
- **自定义语言配置** - 支持在项目根目录放置 `.stats-languages.json` 文件，自定义文件扩展名与语言的映射关系。
- **配置文件示例** - 提供 `stats-languages.example.json` 作为配置模板。
- **动态语言映射** - 支持运行时添加/重置语言映射。

### 🐛 问题修复
- **gitignore 匹配精确化** - 重构 `.gitignore` 规则匹配逻辑，从 `includes()` 模糊匹配改为精确路径段匹配，彻底修复 `layout.tsx`、`about.tsx` 等文件因包含 `out` 而被误排除的问题。
- **glob 模式支持** - 正确解析 `*` 和 `**` 通配符模式。

### 📦 新增模块
- `src/utils/progress-bar.js` - CLI 进度条、Spinner、多阶段进度管理器

## [v3.1.0] - 2025-12-07 - 交互进化版

### 🚀 核心功能升级
- **交互式项目选择** - 彻底告别繁琐的拖拽和命令行参数！双击启动后，工具会自动发现并列出同级的所有项目文件夹，只需输入数字即可一键选择目标项目。
- **全栈项目统计模式** - 新增 `[1] 统计所有项目` 选项，支持一次性扫描父目录下的所有子项目（如 Monorepo），一键生成包含所有子系统的总报告。

### 🐛 关键修复
- **精准路径识别** - 彻底重构了 `shouldExclude` 逻辑，从模糊匹配升级为**精确路径片段匹配**。完美解决了项目名称包含 `build`, `target` 等关键词时被意外排除的问题。
- **智能自我排除 2.0** - 优化了工具自我保护逻辑。现在，当用户明确指定扫描工具所在的目录（或通过交互模式选择工具自身）时，工具将不再“傲娇”地排除自己，而是正确统计源码；仅在扫描父级大项目时自动隐藏自身以避免污染数据。
- **Monorepo 源码识别** - 修复了 `packages/` 目录被误判为第三方库导致 `.ts`/`.tsx` 源码不统计的问题。
- **ESM/CommonJS 兼容性** - 引入 `package.json` 并强制指定 CommonJS 模式，彻底解决了在 ESM 环境下运行时的 `require is not defined` 报错。

## [v2.12.0] - 2025-12-06 - 性能增强与多项目支持版

### 🚀 核心性能与架构优化
- **极速扫描引擎** - 在 `project-scanner.js` 中启用 `readdir({ withFileTypes: true })`，大幅减少 `fs.stat` 调用，文件扫描速度显著提升。
- **并行报告生成** - `OutputManager` 全面升级为并行写入模式，瞬间生成所有报告文件。
- **并发控制** - 优化文件操作，避免在超大项目中触发 `EMFILE` 错误。

### 🔄 多项目支持与隔离
- **按项目隔离历史** - 历史记录现在按项目名称自动分类存储 (`results/<ProjectName>/history.json`)，不再混用全局历史。
- **精准对比分析** - 修复了多项目统计时历史对比混乱的问题，确保只对比同一个项目的历史数据。
- **拖拽分析支持** - 修复了将文件夹拖拽到 `统计项目.bat` 时的路径错误问题，现在完美支持拖拽启动。

### 🛡️ 智能健壮性
- **智能自身排除** - 工具现在能自动识别自己的运行目录，防止将工具自身的代码计入统计结果（无需手动添加 .gitignore）。
- **历史记录备份** - 新增自动备份与恢复机制，防止因意外中断导致历史记录损坏。

### 📚 文档更新
- 更新了所有文档以反映最新的目录结构和功能特性。
