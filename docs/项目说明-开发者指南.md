# 📘 项目统计工具 - 开发者指南

## 🎯 项目概述

**项目名称**: 项目统计工具 (Project Stats Tool)  
**当前版本**: v2.11.0  
**主要功能**: 智能统计项目的代码行数、文字数量和 tokens 估算  
**技术栈**: Node.js + JavaScript (纯原生，无框架依赖)

## 🏗️ 核心架构

### 6 层架构设计

```
┌─────────────────────────────────┐
│ 1️⃣ 入口层 (Entry Layer)         │
│   └─ project-stats.js           │  ← 程序入口，协调所有模块
├─────────────────────────────────┤
│ 2️⃣ 生成层 (Generator Layer)    │
│   ├─ tree-generator.js          │  ← 生成目录树和文件树
│   ├─ text-generator.js          │  ← 生成 Markdown/文本报告
│   ├─ html-generator.js          │  ← 生成 HTML 可视化报告
│   └─ output-manager.js          │  ← 统一管理文件输出
├─────────────────────────────────┤
│ 3️⃣ 核心层 (Core Layer)         │
│   ├─ project-scanner.js         │  ← 扫描项目文件
│   └─ stats-calculator.js        │  ← 计算统计数据
├─────────────────────────────────┤
│ 4️⃣ 分析层 (Analyzer Layer)     │
│   ├─ text-analyzer.js           │  ← 分析文本（中英文统计）
│   ├─ code-analyzer.js           │  ← 分析代码行类型
│   └─ file-analyzer.js           │  ← 分析单个文件
├─────────────────────────────────┤
│ 5️⃣ 工具层 (Utility Layer)      │
│   ├─ formatters.js              │  ← 格式化数字和大小
│   └─ file-utils.js              │  ← 文件类型判断
├─────────────────────────────────┤
│ 6️⃣ 配置层 (Config Layer)       │
│   └─ config.js                  │  ← 集中配置管理
└─────────────────────────────────┘
```

## 🔄 程序执行流程

### 主流程图

```
开始 (main)
  ↓
1. 初始化配置
  ├─ createConfig() - 创建配置对象
  ├─ loadGitignorePatterns() - 加载排除规则
  └─ initStats() - 初始化统计数据
  ↓
2. 扫描项目
  └─ scanProject() 
      └─ walkDirectory() - 递归遍历
          └─ analyzeFile() - 分析每个文件
  ↓
3. 计算统计
  ├─ detectProjectType() - 检测项目类型
  ├─ calculateComplexity() - 计算复杂度
  └─ calculateTokens() - 估算 Tokens
  ↓
4. 历史管理
  ├─ saveRecord() - 保存本次记录
  └─ compare() - 对比历史数据
  ↓
5. 生成报告
  ├─ generateMarkdownReport() - Markdown
  ├─ generateProjectStructure() - 目录树
  ├─ generateFileList() - 文件列表
  ├─ extractAllText() - 完整文字
  └─ generateHTMLReport() - HTML 可视化
  ↓
6. 保存输出
  └─ saveAllReports() - 保存所有文件
  ↓
7. 控制台输出
  ├─ printResults() - 打印统计结果
  └─ printComparison() - 打印对比分析
  ↓
结束
```

## 💡 关键概念

### 1. 统计数据结构 (stats)

```javascript
{
  project: {
    path: "项目路径",
    name: "项目名称",
    type: "项目类型"
  },
  files: {
    total: 0,              // 统计文件总数
    byType: {},            // 按扩展名分类
    byLanguage: {},        // 按语言分类
    largest: {},           // 最大文件信息
    list: [],              // 文件列表
    excluded: {}           // 排除的文件
  },
  text: {
    chineseChars: 0,       // 中文字符数
    englishWords: 0,       // 英文单词数
    totalChars: 0,         // 总字符数
    codeChars: 0           // 代码字符数
  },
  code: {
    totalLines: 0,         // 总行数
    codeLines: 0,          // 代码行
    commentLines: 0,       // 注释行
    blankLines: 0          // 空白行
  },
  tokens: {
    estimated: 0,          // 估算 Tokens
    breakdown: {}          // Tokens 分解
  },
  complexity: {},          // 复杂度指标
  languageStats: {}        // 按语言详细统计
}
```

### 2. 配置对象 (config)

```javascript
{
  rootDir: "项目根目录",
  extensions: {
    code: ['.js', '.ts', ...],  // 代码文件扩展名
    docs: ['.md', '.txt', ...]  // 文档文件扩展名
  },
  defaultExclude: [...],         // 默认排除目录
  libraryDirs: [...],            // 第三方库目录
  libraryFilePatterns: [...],    // 第三方库文件特征
  tokenEstimate: {}              // Tokens 估算规则
}
```

## 🚨 常见问题

### Q: 如何排除某些文件或目录？
**A**: 在项目根目录的 `.gitignore` 文件中添加规则即可。

### Q: 如何修改 Tokens 估算规则？
**A**: 编辑 [`src/config.js`](../src/config.js:1) 中的 `tokenEstimate` 配置。

### Q: 如何添加新的编程语言支持？
**A**: 在 [`src/config.js`](../src/config.js:1) 的 `LANGUAGE_MAP` 和 `extensions.code` 中添加。

### Q: 模块依赖关系如何管理？
**A**: 遵循分层架构原则，上层模块可以引用下层，下层不能引用上层。

## 🎓 核心设计原则

1. **单一职责** - 每个模块只做一件事
2. **开闭原则** - 对扩展开放，对修改关闭
3. **依赖倒置** - 依赖抽象而非具体实现
4. **接口隔离** - 模块间通过清晰的接口通信
5. **分层架构** - 严格的层次结构，职责清晰
