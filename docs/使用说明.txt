🚀 使用方法
──────────────────────────────────────────────────────

【方法 1】双击运行（推荐）
  双击: 统计项目.bat
  功能: 自动统计当前目录
  位置: 工具根目录

【方法 2】拖放操作（推荐）
  将项目文件夹拖到 统计项目.bat 上
  自动统计指定项目（支持任意位置的项目）

【方法 3】命令行
  node src/project-stats.js              # 统计当前目录
  node src/project-stats.js ../my-app    # 统计指定项目

【方法 4】查看历史
  双击: 查看历史.bat
  或: node src/view-history.js
  
  命令:
    node src/view-history.js                # 列表
    node src/view-history.js detail 3       # 查看第3条详情
    node src/view-history.js compare 1 5    # 对比第1和第5条

📊 统计内容
──────────────────────────────────────────────────────

1. 项目信息
   - 项目名称和路径
   - 自动检测的项目类型

2. 文件统计
   - 统计文件数（实际代码）
   - 排除文件数（第三方库）
   - 按语言分布

3. 文字统计
   - 中文字符数
   - 英文单词数
   - 总字符数和文件大小

4. 代码统计
   - 总行数
   - 代码行、注释行、空白行的数量和占比

5. 语言详细统计
   - 每种语言的文件数
   - 每种语言的代码行、注释行、空白行
   - 每种语言的总字符数
   - 每种语言的中文字符和英文单词

6. 复杂度分析
   - 平均行长度
   - 平均文件大小
   - 最大文件和最长行

7. Tokens 估算
   - 基于实际代码的准确估算
   - 不包含第三方库

8. 历史对比分析
   - 自动对比该项目上次统计
   - 显示增减变化和百分比
   - 历史趋势图表

📁 输出文件说明
──────────────────────────────────────────────────────

所有输出文件都保存在 results/ 文件夹中，按项目名分类：

results/
├── MyProject/                     # 项目名称
│   ├── 最新/                      # 快捷访问
│   │   ├── 统计数据.json
│   │   ├── 统计报告.md
│   │   ├── 可视化报告.html
│   │   ├── 项目结构.txt
│   │   ├── 文件列表.txt
│   │   └── 完整提取.txt
│   │
│   ├── 2025-11-04_10-30-11/       # 历史备份
│   └── history.json               # 历史索引
│
└── OtherProject/                  # 其他项目
    └── ...

⚙️ 自动排除的内容
──────────────────────────────────────────────────────
• node_modules, vendor, venv (依赖包)
• .git, .svn, .hg (版本控制)
• dist, build, out, target (构建产物)
• .idea, .vscode (IDE 配置)
• lib, libs, library 目录（库文件）
• .min.js, .min.css 文件（压缩文件）
• 知名第三方库文件
• results (统计结果)
• 还会自动读取项目的 .gitignore 文件
• 工具自身的代码文件（智能识别）
