🚀 使用方法
──────────────────────────────────────────────────────

【方法 1】双击运行（推荐）
  双击: 统计项目.bat
  功能: 统计 + 报告 + 文字提取 一步完成
  位置: 工具根目录

【方法 2】拖放操作
  将项目文件夹拖到 统计项目.bat 上
  自动统计指定项目

【方法 3】命令行
  node src/project-stats.js              # 统计当前目录
  node src/project-stats.js ../my-app    # 统计指定项目

【方法 4】查看历史
  双击: 查看历史.bat
  或: node src/view-history.js
  
  命令:
    node src/view-history.js                # 列表
    node src/view-history.js detail 3       # 查看第3条详情
    node src/view-history.js compare 1 5    # 对比第1和第5条

【方法 5】查看可视化“历史对比分析”
  生成报告后，打开: results/最新/可视化报告.html
  在“历史对比分析”区块右上角，点击按钮：
    • 隐藏对比  → 折叠对比卡片
    • 显示对比  → 展开对比卡片
  说明：
    • 至少需要 2 条历史记录（第2次运行后自动具备）
    • 对比基准为“上一次统计”，显示时间及可选标签


📊 统计内容
──────────────────────────────────────────────────────

1. 项目信息
   - 项目名称和路径
   - 自动检测的项目类型

2. 文件统计
   - 统计文件数（实际代码）
   - 排除文件数（第三方库）
   - 按语言分布

3. 文字统计
   - 中文字符数
   - 英文单词数
   - 总字符数和文件大小

4. 代码统计
   - 总行数
   - 代码行、注释行、空白行的数量和占比

5. 语言详细统计（v2.10 新增）
   - 每种语言的文件数
   - 每种语言的代码行、注释行、空白行
   - 每种语言的总字符数
   - 每种语言的中文字符和英文单词

6. 复杂度分析
   - 平均行长度
   - 平均文件大小
   - 最大文件和最长行

7. Tokens 估算
   - 基于实际代码的准确估算
   - 不包含第三方库

8. 历史对比分析
   - 自动对比上次统计
   - 显示增减变化和百分比
   - 历史趋势图表

🎯 文字提取说明
──────────────────────────────────────────────────────

完整提取文件（完整提取.txt）包含:
  • 项目基本信息
  • 排除的库文件统计
  • 按语言分类的所有文件
  • 每个文件的完整内容
  • 文件路径和大小信息

提取文件用途:
  ✓ 向 AI 提供完整项目上下文
  ✓ 代码审查和分析
  ✓ 项目归档备份
  ✓ 快速浏览所有代码
  ✓ 文档生成


🎯 注意事项
──────────────────────────────────────────────────────
• 需要安装 Node.js 环境（≥12.0.0）
• Tokens 估算为粗略值，实际可能有 ±20% 偏差
• 大型项目统计可能需要几秒到几十秒
• 完整提取文件可能很大（几MB到几十MB）
• 二进制文件和无权限目录会自动跳过
• results 文件夹不会被统计
• 第三方库文件会被智能识别并排除
• 本工具零外部依赖，开箱即用


🛡️ 安全说明
──────────────────────────────────────────────────────
✅ 工具只读取文件，不修改任何项目文件
✅ 自动排除敏感目录（.git, node_modules 等）
✅ 支持 .gitignore 规则，尊重项目配置
✅ 所有结果仅保存在 results 文件夹
✅ 提取的文字内容是纯文本，无安全风险
✅ 智能识别第三方库，保护项目隐私
✅ 本地运行，数据不外传

📊 Token 估算规则
──────────────────────────────────────────────────────
• 中文: ~1.5 字符/token
• 英文: ~1.3 单词/token
• 代码: ~3.5 字符/token

这些规则基于常见 AI 模型的 tokenizer 特性，
适用于 GPT-3.5/4、Claude 等主流模型。
